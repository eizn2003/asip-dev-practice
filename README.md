# ASIP DEV PRACTICE TASK

## Title: Furni App

## Tech Stack

1. HTML
2. CSS
3. Vanilla JavaScript

## About

Furni is a simple furniture store e-commerce frontend application built with HTML, CSS, and Vanilla JavaScript. It demonstrates product listing and search functionality using locally stored dummy data.

The project does not use an actual server API. Instead, it simulates API functionality by fetching product data from an `assets.js` file.

The JavaScript codebase follows a component-based structure to keep the code organized, reusable, and easier to maintain.

This project does not use any organization's data or source code, including any ASIP project source code. All product data was manually created as dummy data for demonstration purposes.

The application is frontend-only and does not include full-stack functionality such as product uploads, user authentication, a functional shopping cart, checkout, or payment processing.

## How to Use

1. Clone the GitHub repository.
2. Open the project in VS Code.
3. Run the project using a local development server such as **Live Server** or **Live Preview**.
4. Open the provided local server URL in your browser.
